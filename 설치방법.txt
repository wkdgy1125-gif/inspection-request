검측요청서 작성기 - 웹앱 설치·공유 방법
=====================================

주소: https://wkdgy1125-gif.github.io/inspection-request/

1. 팀 공유 서버 만들기 (처음 한 번, 약 5분)
------------------------------------------
담이 캘린더처럼 Cloudflare Worker 하나가 팀 공유 저장소 역할을 합니다.
  1) dash.cloudflare.com 로그인 (담이 캘린더 만든 계정)
  2) Storage & Databases → D1 SQL Database → Create
     → 이름: inspection-request → Create
  3) Workers & Pages → Create → Worker
     → 이름: gcr-api → Deploy
  4) Edit code → 기존 내용 지우고 gcr-api-worker.js 내용 전체 붙여넣기 → Deploy
  5) gcr-api → Settings → Bindings → Add → D1 database
     → Variable name: DB / D1 database: inspection-request → Save (→ Deploy)
  6) https://gcr-api.wkdgy1125.workers.dev/api/ping 을 열어
     {"ok":true,"app":"gcr"} 가 보이면 완료

  ※ 워커 주소가 다르면 index.html 안의
     window.GCR_API||'https://gcr-api.wkdgy1125.workers.dev'
     부분을 그 주소로 바꿔 올리세요.

2. 팀원 사용
------------
  - 위 주소를 팀원에게 알려주면 비밀번호 없이 바로 보고 편집할 수 있습니다.
  - 검측번호마다 따로 저장되어 여러 사람이 다른 번호를 동시에 작성할 수 있습니다.
  - 같은 번호를 연 사람끼리는 약 10초 안에 서로의 수정이 반영됩니다.

3. 휴대폰·PC에 앱으로 설치
--------------------------
  [안드로이드 크롬] 주소 접속 → 왼쪽 위 '앱 받기' → 홈 화면에 앱 설치
                    (또는 메뉴 ⋮ → 앱 설치)
  [아이폰 사파리]   주소 접속 → 아래 공유 버튼 → 홈 화면에 추가
  [PC 크롬/엣지]    주소창 오른쪽 설치 아이콘

4. 개인정보
-----------
  - 이 저장소는 공개(Public)라 누구나 코드를 볼 수 있습니다.
    그래서 실명부 기본 명단(생년월일)은 넣지 않았습니다.
    실명부 탭의 '엑셀에서 명단 불러오기'로 한 번 불러오면 팀 공유 서버에 저장됩니다.
  - 작성 내용·서명·사진은 GitHub가 아니라 팀 공유 서버(Cloudflare)에 저장됩니다.
