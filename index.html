파일로 받기 (고급)
설치용 묶음은 이렇게 쓰세요
  1. zip 파일 압축을 풉니다(파일 5개).
  2. PC 브라우저에서 app.netlify.com/drop 에 들어가 풀린 폴더를 통째로 끌어다 놓습니다(무료). GitHub Pages에 올려도 됩니다.
  3. 생긴 인터넷 주소를 휴대폰 Chrome·Safari로 열고 ‘앱 받기 → 홈 화면에 앱 설치’(아이폰은 공유 → 홈 화면에 추가)를 누릅니다.
  4. 설치 후에는 인터넷이 끊겨도 작성·PDF 저장이 됩니다(처음 한 번은 인터넷 연결 필요).

작성 내용은 기기·주소마다 따로 저장됩니다. 옮길 때는 ‘파일 → 작업파일 저장/불러오기’를 쓰세요.
